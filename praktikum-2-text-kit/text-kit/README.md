# Text Kit (Учебный проект)

## Назначение программы
`text-kit` — это учебный Python-проект, представляющий собой набор независимых модулей с полезными утилитами. 

Программа не решает одну конкретную прикладную задачу, а служит демонстрационной площадкой (песочницей) для проверки работы написанных функций. В ней реализованы:
- Обработка и форматирование текста (очистка пробелов, сокращение, генерация slug, инициалы).
- Базовая математическая статистика (среднее, медиана, разброс, подсчет значений).
- Валидация и нормализация пользовательских данных (email, телефоны, пароли).
- Утилиты для работы с датами (парсинг, форматирование, определение выходных, разница дней).

## Дерево проекта

```text

├── app/
│   ├── __init__.py
│   ├── main.py                 # Точка входа. Запускает демонстрацию всех утилит.
```

## Команды запуска

Для запуска демонстрационного скрипта необходимо открыть терминал в корневой папке проекта (`text-kit`) и выполнить команду:

```bash
python -m app.main
```
*(Использование флага `-m` обязательно, так как проект использует абсолютные импорты внутри пакета `app`)*

Для запуска тестов (если используется `pytest`):
```bash
pytest
```
